# Security policy

Please do not disclose scanner addresses, credentials, scanned documents, or exploitable details in a public issue.

For a suspected vulnerability, use GitHub's private Security Advisory form for [yowmamasita/brscan-mac](https://github.com/yowmamasita/brscan-mac/security/advisories/new). Include the affected version, reproduction steps using synthetic data where possible, and the impact. If private advisories are unavailable, contact the maintainer through the repository's GitHub profile before posting details publicly.

This tool sends data only to the configured scanner host and writes output to the local filesystem. Do not run it with an untrusted host or an output path you do not control.
